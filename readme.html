🧠 Brain Tumor Classifier 🩻 | PyTorch + Grad-CAM + Flask

🎯 A Deep Learning–powered Web App to detect brain tumors (Glioma, Meningioma, Pituitary, or No Tumor) from MRI scans using ResNet18 and Grad-CAM visualization.

🚀 Live Demo

👉 Click Here to Try the App (Deployed on Render)

(Or run locally using instructions below)

🧠 Features

  • 🔍 Classifies Brain MRIs into:
    • Glioma Tumor
    • Meningioma Tumor
    • Pituitary Tumor
    • No Tumor
  • 📸 Shows Grad-CAM heatmaps for model explainability
  • 🧪 Built with PyTorch + ResNet18, achieving 99.7% accuracy
  • 💻 Clean UI with preview thumbnails
  • 📂 Drag & Drop file upload
  • 🧠 Chatbot Assistant for medical guidance (rule-based)

💻 Run Locally

1️⃣ Clone the Repo

git clone https://github.com/your-username/brain-tumor-classifier.git
cd brain-tumor-classifier

2️⃣ Create Environment

python -m venv brainenv
brainenv\Scripts\activate   # On Windows
# source brainenv/bin/activate   # On Linux/Mac

3️⃣ Install Dependencies

pip install --upgrade pip
pip install -r requirements.txt

4️⃣ Run the App

python app.py

Then visit: http://127.0.0.1:5000

☁️ Deployment (Render)

  1. Push code to GitHub (private/public)
  2. Go to https://render.com
  3. Click New Web Service
  4. Connect GitHub → Select repo
  5. Set build command: pip install -r requirements.txt
  6. Set start command: python app.py
  7. Done ✅
